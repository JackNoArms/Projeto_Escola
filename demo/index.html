05 · SOBRE O PROJETO

Da organização dos cadastros à visão acadêmica.

O Sistema Escola foi criado com Oracle APEX e inclui páginas para professores, matérias, alunos e séries. Esta demonstração web reproduz os principais conceitos de gestão acadêmica com dados fictícios, sem necessidade de uma conta Oracle.

A versão Oracle APEX e sua exportação original permanecem no repositório para estudo da estrutura de páginas, relatórios e formulários.
